# Bullshark Roadmap

**This is a work in progress and is subject to change.**

## Short Term Goals

- Focus on core features and stability
- Focus on Quality of Life (QoL) improvements and bug fixes
- Extend the plugin SDK
- Improve documentation and developer experience

## Medium Term Goals

- Gaming-grade voice: audio must stay clean while a game saturates the CPU
- GPU-encoded screen sharing on Windows
- Audio redundancy (RED) for lossy connections
- Import a Discord server (channels, roles, permissions) from a template link

## Long Term Goals

- v1.0.0 stable
- Next-generation Opus packet-loss recovery (DRED) once browsers ship it
